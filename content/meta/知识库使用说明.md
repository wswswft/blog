# 知识库使用说明

这个知识库参考 Researcher 模板，以可链接的概念笔记和 MOC（Map of Content）为核心。

## 目录职责

- `concepts/`：可跨项目复用的长期知识。
- `projects/`：项目目标、规范和项目专属材料。
- `tools/`：工具用法和命令速查。
- `scratch/`：未整理的临时记录与每日笔记，Quartz 不发布。
- `templates/`：Obsidian 笔记模板，Quartz 不发布。
- `meta/`：维护知识库本身的规则和复盘。

## 编写规则

1. 新内容先写入 `scratch/`，成熟后再提炼为概念笔记。
2. 一篇概念笔记围绕一个可清晰命名的主题。
3. 通过 `[[内部链接]]` 表达知识关系，通过 MOC 表达学习顺序。
4. 图片和 PDF 放在所属主题的 `assets/` 中。
5. 标签用来表达类型或状态，不复制整套文件夹层级。

## 工作流

`scratch 捕获 → concept 提炼 → MOC 连接 → project 应用 → meta 复盘`
