# 博客基本构成

文章统一使用 Markdown 格式进行编辑。在使用 Markdown 时，需加入文件头（基本格式如下）。

```yaml
---
title: "文章编辑规则"
description: "markdown学习：快速入门"
tags:
  - markdown
cover: assets/markdown.png
modified: 2026-08-09
---
```

## Frontmatter 可选字段表

| 分类       | 字段                         | 类型         | 示例                                     | 默认/建议值        | 作用与说明                                                            |
| ---------- | ---------------------------- | ------------ | ---------------------------------------- | ------------------ | --------------------------------------------------------------------- |
| 基础信息   | `title`                      | 字符串       | `title: "文章编辑规则"`                  | 建议填写           | 页面标题；未填写时使用文件名                                          |
| 基础信息   | `description`                | 字符串       | `description: "Markdown 快速入门"`       | 建议填写           | 页面简介，用于搜索、列表和网页元数据                                  |
| 基础信息   | `tags`                       | 字符串列表   | `tags: [markdown, 教程]`                 | `[]`               | 设置文章标签                                                          |
| 基础信息   | `tag`                        | 字符串或列表 | `tag: markdown`                          | —                  | `tags` 的别名，不建议和 `tags` 同时使用                               |
| 基础信息   | `aliases`                    | 字符串列表   | `aliases: [Markdown 教程, MD 入门]`      | `[]`               | 设置文章别名，可用于 Wiki 链接解析                                    |
| 基础信息   | `alias`                      | 字符串或列表 | `alias: Markdown 教程`                   | —                  | `aliases` 的别名，不建议和 `aliases` 同时使用                         |
| 页面地址   | `permalink`                  | 字符串       | `permalink: tutorials/markdown`          | 使用文件路径       | 自定义文章访问路径，同时作为页面别名                                  |
| 页面样式   | `cssclasses`                 | 字符串列表   | `cssclasses: [wide-page, tutorial]`      | `[]`               | 为当前页面添加自定义 CSS 类                                           |
| 页面样式   | `cssclass`                   | 字符串或列表 | `cssclass: wide-page`                    | —                  | `cssclasses` 的别名                                                   |
| 封面与分享 | `cover`                      | 路径或 URL   | `cover: assets/markdown.png`             | 无                 | 设置文章封面或社交分享图片                                            |
| 封面与分享 | `socialImage`                | 路径或 URL   | `socialImage: assets/share.png`          | 使用默认图片       | 单独设置社交媒体分享预览图                                            |
| 封面与分享 | `image`                      | 路径或 URL   | `image: assets/share.png`                | —                  | `socialImage`、`cover` 的同类字段                                     |
| 封面与分享 | `socialDescription`          | 字符串       | `socialDescription: "快速掌握 Markdown"` | 使用 `description` | 单独设置社交媒体分享简介                                              |
| 日期       | `created`                    | 日期         | `created: 2026-08-01`                    | 自动推断           | 文章创建日期                                                          |
| 日期       | `date`                       | 日期         | `date: 2026-08-01`                       | 自动推断           | 可作为创建日期或发布日期                                              |
| 日期       | `modified`                   | 日期         | `modified: 2026-08-09`                   | 自动推断           | 文章最后修改日期                                                      |
| 日期       | `lastmod`                    | 日期         | `lastmod: 2026-08-09`                    | —                  | `modified` 的别名                                                     |
| 日期       | `updated`                    | 日期         | `updated: 2026-08-09`                    | —                  | `modified` 的别名                                                     |
| 日期       | `last-modified`              | 日期         | `last-modified: 2026-08-09`              | —                  | `modified` 的别名                                                     |
| 日期       | `published`                  | 日期         | `published: 2026-08-09`                  | 无                 | 文章发布日期                                                          |
| 日期       | `publishDate`                | 日期         | `publishDate: 2026-08-09`                | —                  | `published` 的别名                                                    |
| 发布控制   | `draft`                      | 布尔值       | `draft: false`                           | `false`            | 为 `true` 时不生成、不发布文章                                        |
| 发布控制   | `publish`                    | 布尔值       | `publish: true`                          | —                  | Explicit Publish 插件启用后用于指定文章是否发布；本站目前未启用该插件 |
| 发布控制   | `unlisted`                   | 布尔值       | `unlisted: true`                         | `false`            | 文章仍可通过直链访问，但不会出现在搜索、目录、图谱和文章列表中        |
| 页面设置   | `lang`                       | 字符串       | `lang: zh-CN`                            | 使用站点语言       | 设置当前文章的语言                                                    |
| 页面设置   | `enableToc`                  | 布尔值       | `enableToc: true`                        | `true`             | 是否显示文章目录                                                      |
| 页面设置   | `comments`                   | 布尔值       | `comments: false`                        | 取决于评论配置     | 控制当前文章是否显示评论；本站评论插件目前未启用                      |
| 属性面板   | `quartz-properties`          | 布尔值       | `quartz-properties: true`                | 使用全局配置       | 强制显示或隐藏 Frontmatter 属性面板                                   |
| 属性面板   | `quartz-properties-collapse` | 布尔值       | `quartz-properties-collapse: true`       | 使用全局配置       | 设置属性面板默认折叠或展开                                            |
| 文章加密   | `password`                   | 字符串       | `password: "example-password"`           | 无                 | 设置文章访问密码；不要在公开仓库中提交真实密码                        |
| 文章加密   | `stealth`                    | 布尔值       | `stealth: true`                          | `false`            | 配合 `password` 使用，使文章始终不出现在站内发现入口中                |

## 常用字段模板

```yaml
---
title: "文章标题"
description: "文章简介"
tags:
  - markdown
  - 教程
aliases:
  - 文章别名
cover: assets/markdown.png
created: 2026-08-01
modified: 2026-08-09
published: 2026-08-09
lang: zh-CN
draft: false
unlisted: false
enableToc: true
---
```
