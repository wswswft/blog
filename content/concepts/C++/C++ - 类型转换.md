# C++ - 类型转换

## 类型转换

- C\+\+提供了四种显式类型转换操作符，用来替代不安全的C风格转换：

### **static\_cast**

- 用于相关类型之间的安全转换，只在编译时进行检查

- 例如`static_cast<int>(car.label)`将float类型的`car.label`转换为int类型

- 所有的隐式转换都可以用静态转换来替代

- 这种转换在编译时检查类型兼容性，比C风格转换更安全

### **const\_cast**

- 用于添加或移除const/volatile属性

- 转换类型必须是指针或者引用`const_cast<目标类型>(源对象);`

- 示例：`const_cast<int*>(ptr)`可以移除指针的const属性

- 具体用途：

    - 修改普通变量的const指针

    - 类的const成员函数中修改成员变量

    - 注意真正的const常量，不能修改

### **reinterpret\_cast**

- 不会检查所转换的类型是否有效

- 用于低级别的位转换，比如指针和整数之间转换

- 示例：`reinterpret_cast<uintptr_t>(ptr)`将指针转换为整数，注意精度不够会报错

- 主要用于：

    - 与内存和硬件的直接交互的底层程序和接口程序

    - 与操作系统组件进行交互，需要精确数据格式

    - 处理网络或多媒体数据的应用程序

### **dynamic\_cast**

- 只能用于对对象的指针和引用的转换

- 主要用于多态类的向下转换，从基类向派生类的转换；也可以用来做向上转换，但由于向上转换100%成功，且dynamic\_cast运算符开销大于普通运算符，所以直接使用普通运算符即可

- dynamic\_cast对类型转换包含两个阶段的检查

    - 编译阶段检查：检查是否为多态类

    **`dynamic_cast`****能生效的唯一前提**：被转换的这个类，**必须包含至少一个虚函数（virtual）** ，也就是这个类是**多态类**。

    `dynamic_cast`是**运行期类型检查**，它的底层实现依赖于 C\+\+ 的 **虚函数表 \(vtable\)** 和 **RTTI 机制**（Run\-Time Type Information，运行时类型信息）。

    - 执行阶段：检查 **「源对象的实际类型」** 是否是「目标类型」或者「目标类型的子类」，满足则转换成功，否则失败

`dynamic_cast` 针对 **指针** 和 **引用** 两种类型，转换失败时的**行为完全不同；核心原因：C\+\+ 中引用永远不能为 NULL，引用的语法规则就是「必须绑定有效对象」，所以没办法像指针一样返回 nullptr，只能用抛异常的方式来处理转换失败。**

```C++
// 1. 指针类型的dynamic_cast
目标类指针  = dynamic_cast<目标类*>(源指针);

// 2. 引用类型的dynamic_cast
目标类引用  = dynamic_cast<目标类&>(源引用);
```

##### `dynamic_cast` 转换【指针】

1. 转换**成功**：返回指向目标类型对象的**有效指针**；

2. 转换**失败**：返回一个 **`nullptr`**** \(空指针\)** ；

3. 特点：**失败不会抛异常**，可以通过判断返回值是否为 nullptr，来处理转换失败的情况。

##### `dynamic_cast` 转换【引用】

1. 转换**成功**：返回目标类型对象的**有效引用**；

2. 转换**失败**：**直接抛出 C\+\+ 标准异常 ****`std::bad_cast`** 

3. 特点：**失败必抛异常**，所以引用的 dynamic\_cast 必须写在`try{}`块中，并用`catch(bad_cast& e)`捕获异常。
