# C++ - 右值引用与移动语义

## 右值引用和移动语义

### 左值和右值

左值和右值指的是表达式

```C++
const int a; // 常量a是不可修改的左值
//左值引用的赋值运算符右侧必须是一个左值
```

**左值 \(lvalue\)又被叫做****`locator value`****:能够代表一块内存区域的表达式**

C\+\+ 11以后，分为：泛左值**\(glvalue\)**\(左值** \(lvalue\)**，将亡值** \(xvalue\)\)**，纯右值** \(prvalue\)**
